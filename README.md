# 🏆 Ranking Board (PWA 対応 リアルタイムランキングシステム)

イベントや大会などで利用できる、リアルタイム更新・自動ページローテーション機能を備えた PWA 対応のランキング表示システムです。  
PC、タブレット、大型モニターなどの画面サイズ（高さ）を自動判定し、最適な件数を美しく表示します。

---

## ✨ 主な機能

- **画面サイズに応じた自動件数調整**
  - 画面の高さを検知し、スクロール不要で収まる最適な表示件数を自動計算します。
- **自動ページローテーション**
  - 参加者が多数の場合でも、設定した間隔（デフォルト: 6秒）で次のページへ自動的に切り替わります。
- **日時依存の動的表示ルール (JST 12:00 判定)**
  - **1日目タブ**: 1日目のデータを表示
  - **2日目タブ (12:00 前)**: 「2日目単体」と「2日合計」のランキングを6秒ごとに交互表示
  - **2日目タブ (12:00 以降)**: 「2日合計」のみを自動で固定表示
  - **2日合計タブ**: 2日合計のデータを表示
- **全画面 (フルスクリーン) 表示対応**
  - フルスクリーン切替時に画面領域を再計算し、表示件数を即座に自動最適化します。
- **PWA (Progressive Web Apps) 対応**
  - サービスワーカー (`sw.js`) および `manifest.json` を備え、スタンドアロンアプリ感覚で利用可能です。
- **管理者画面の分離**
  - 閲覧用画面 (`index.html`) と管理用画面 (`admin.html`) を分離し、安全かつシンプルなアクセスを実現。

│   ├── auth.js           # 認証制御スクリプト
│   ├── config.js         # API・フォーム接続設定 (GAS URL等)

│   └── viewer.js         # 閲覧画面コアロジック (ローテーション・自動件数計算)
